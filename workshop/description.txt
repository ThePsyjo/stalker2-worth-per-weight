Shows each item's value per kilogram right next to its price in every item tooltip, so you can see at a glance what is worth carrying.

Example: SEVA-I Suit  45k/kg · 312750 ₭

[h2]Details[/h2]
[list]
[*]Uses the price the tooltip shows: upgrades, durability and items from other mods are included automatically.
[*]Inventory, traders, stashes and containers. Values below 500 per kg show as <1k/kg.
[*]Item names are not changed, so it works together with renaming mods like True Gun Names.
[*]Pure Workshop mod (Blueprint), no extra tools to install.
[/list]

[h2]Notes[/h2]
The value appears a moment after the tooltip opens. On some long weapon tooltips it can touch the weight display.
Traders pay only part of the shown price; use the value to compare items.
Built for game version 2.0.6. Source and build tools: https://github.com/ThePsyjo/stalker2-worth-per-weight
